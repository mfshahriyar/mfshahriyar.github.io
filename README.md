# mfshahriyar.github.io

Personal academic website of **Md. Farhan Shahriyar**: plain HTML, CSS and JS with no build step. It's served by GitHub Pages.

## Files
- `index.html`: all content (about, news, publications, experience, contact)
- `style.css`: styling, including light and dark themes
- `script.js`: dark-mode toggle, mobile menu and footer year
- `assets/profile.svg`: placeholder photo. Replace it with your own (for example `assets/profile.jpg`) and update the `<img src>` in `index.html`.

## To customise
1. Replace `you@example.com` in `index.html` (two places) with your email.
2. Replace the placeholder publications with your real papers. Copy a `<li class="pub">` block for each paper.
3. Add news items as new `<tr>` rows in the news table.

## Deploy
Repo **Settings → Pages → Build and deployment**: Source "Deploy from a branch", branch `main`, folder `/ (root)`.
The site will be live at https://mfshahriyar.github.io/
