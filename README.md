# mfshahriyar.github.io

Personal academic website of **Md. Farhan Shahriyar**: plain HTML, CSS and JS with no build step. It's served by GitHub Pages.

## Files
- `index.html`: all content (sidebar profile, about, research interest, news, publications, research topics, experience, contact)
- `style.css`: styling
- `script.js`: sticky-nav highlighting, mobile menu and footer year
- `assets/profile.jpg`: profile photo shown in the sidebar.
- `assets/publications/`: paper thumbnails

## To customise
1. Replace `your.email[at]example[dot]com` in `index.html` with your email.
2. Publications: copy an `<article class="pub">` block for each paper, and fill in the title, authors, venue and links. Add a thumbnail in `assets/publications/`.
3. News: add a new `<li>` at the top of the news list.

## Deploy
Repo **Settings → Pages**: Source "Deploy from a branch", branch `main`, folder `/ (root)`.
The site will be live at https://mfshahriyar.github.io/
